BLUEBELL STUDY - how to put it online (GitHub Pages)
1. Make a GitHub repo with a hard-to-guess name (for example: bb-7k2q9x).
2. Upload ALL files in this folder to the repo (not the zip itself).
3. Settings > Pages > Source: "Deploy from a branch", branch main, folder /root. Save.
4. Open the address GitHub shows (https://YOURNAME.github.io/REPO/) on her Android phone in Chrome.
5. Chrome menu (three dots) > "Install app" or "Add to Home screen".
To update later: replace index.html in the repo with the new one. Her saved study time stays on her phone.
